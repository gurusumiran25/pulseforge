## Envelope fields

| Field | Validation behavior |
| --- | --- |
| `event_id` | Nonempty string |
| `event_name` | One of the eight supported event names |
| `schema_version` | Exactly `1` |
| `event_time` | Timezone-aware datetime normalized to UTC |
| `user_id`, `session_id` | Nonempty strings |
| `source`, `platform` | Nonempty strings |
| `properties` | Dictionary with event-specific required keys |
| `ingested_at` | Optional timezone-aware datetime normalized to UTC |

Unknown top-level envelope fields are rejected (`extra="forbid"`). Event-specific required properties must exist and cannot be null or blank strings.

## Event-specific required properties

| Event name | Required `properties` |
| --- | --- |
| `page_view` | `page_path` |
| `search_performed` | `search_category`, `result_count` |
| `product_viewed` | `product_id`, `category`, `price`, `currency` |
| `add_to_cart` | `product_id`, `quantity`, `unit_price`, `currency` |
| `checkout_started` | `cart_value`, `item_count`, `currency` |
| `payment_succeeded` | `order_id`, `amount`, `currency`, `payment_method_category` |
| `payment_failed` | `order_id`, `failure_code_category` |
| `order_refunded` | `order_id`, `refund_amount`, `currency`, `reason_category` |

## Additional validations

- `quantity` and `item_count`, when supplied, must be positive integers (booleans are rejected).
- `result_count`, when supplied, must be a nonnegative integer.
- `price`, `unit_price`, `cart_value`, `amount`, and `refund_amount`, when supplied, must be finite, nonnegative numbers (booleans are rejected).
- `currency`, when supplied, must be a three-letter uppercase ASCII alphabetic code.
- Required fields are checked for presence and nonempty values, but not all property values have a dedicated type validator. Do not describe the contract as a complete strict per-event schema.

## Event lifecycle

Synthetic journeys emit a subset of these event types based on simulated behavior. The standard generator can end after product view, cart addition, or checkout, and may emit payment success or failure. `order_refunded` is supported by validation and revenue analytics but is **not generated by the basic journey generator**.

Events are synthetic. Do not use real personal information or secrets in event properties.
